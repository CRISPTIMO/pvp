# ШТРАФОСТАН TOOLS — сервер-релей координат

Крошечный сервер, через который клиенты обмениваются координатами, чтобы видеть
своих **на любой дистанции** (ванильный MC-сервер этого не даёт). Работает мимо
игрового сервера, поэтому пашет на любом сервере.

- Только стандартная библиотека Python 3 — никаких зависимостей.
- Хранит позиции в памяти, отдаёт свежие (моложе TTL).
- Защита простым общим токеном (паролем команды).

## Установка на Linux-VDS (systemd, автозапуск после ребута)

Закинь папку `relay` на VDS (scp/sftp) и от root (токен уже вшит):

```bash
sudo bash install.sh
```

Скрипт: поставит python3 при необходимости, скопирует в `/opt/shtrafostan-relay`,
создаст и включит systemd-сервис (стартует сам после перезагрузки VDS).

Открой порт в фаерволе:
```bash
sudo ufw allow 8080/tcp     # если используется ufw; иначе — в панели хостера
```

Проверка:
```bash
systemctl status shtrafostan-relay
curl http://localhost:8080/health      # должно ответить: ok
journalctl -u shtrafostan-relay -f     # живой лог
```

## Управление

```bash
sudo systemctl restart shtrafostan-relay   # перезапуск
sudo systemctl stop shtrafostan-relay      # остановить
sudo systemctl disable shtrafostan-relay   # убрать из автозапуска
```

Сменить токен/порт: отредактируй `/etc/systemd/system/shtrafostan-relay.service`
(строки `Environment=`), затем `sudo systemctl daemon-reload && sudo systemctl restart shtrafostan-relay`.

## Настройка мода (у каждого в команде)

`config/pvphelper-client.toml`, секция `[relay]` (токен уже вшит в дефолт —
трогать не надо, укажи только IP своей VDS):

```toml
[relay]
    enabled = true
    url = "http://IP_ТВОЕЙ_VDS:8080"
    # token уже проставлен по умолчанию (SHTRAFOSTAN-...), менять не нужно
```

После этого включи в HUD список координат (клавиша **Numpad .**) — свои будут
зелёными и с пометкой ⇄, даже если они за тысячи блоков или в другом измерении.

## Безопасность

- Токен — это весь контроль доступа. Не публикуй его. Кто знает токен — видит
  координаты команды и может слать фейковые. Меняй при утечке.
- Трафик по HTTP (не шифрован). Для игры норм; если нужен HTTPS — поставь за
  nginx с сертификатом, но обычно избыточно.
