# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проект

**PvP Helper** — клиентский мод для Minecraft **1.21.11** на **MinecraftForge 61.1.0** (Java 21). Помощник для PvP. `clientSideOnly=true` — на выделенном сервере не грузится.

Фичи (переключаются клавишами на нумпаде + мастер-тумблер в конфиге; активны, если И флаг `enabled`, И `PvpConfig.*.get()`):

1. **Авто-тотем** (`feature/AutoTotem.java`) — если в offhand нет тотема, перекладывает из инвентаря через `MultiPlayerGameMode.handleInventoryMouseClick` (работает с закрытым GUI). Numpad 1.
2. **Авто-инструмент** (`feature/AutoTool.java`) — на `LeftClickBlock` выбирает инструмент с макс. `getDestroySpeed`; на `AttackEntityEvent` — предмет с макс. **DPS** (урон × скорость атаки — меч выигрывает у топора). Слот не трогается, если ничего строго лучше текущего нет. Numpad 2.
3. **Помощь прицела** (`feature/AimAssist.java`) — лук/яйцо/снежок/жемчуг: цель выбирается **в конусе взгляда** (30°, удержание 50°), захватывается на время прицеливания; траектория всегда на ПОЛНУЮ скорость (натяг не отслеживаем — дёргало прицел); частично укрытые цели таргетятся в видимую точку (`Los.visibleAimPoint`: грудь 0.65 → голова 0.9 → ноги 0.2); доводка плавная (0.55/тик, snap <0.4°). Дальность лука 128, метательных — из конфига. Numpad 3; **V — тумблер** наводки метательных (не удержание).
4. **Авто-рыбалка** (`feature/AutoFish.java`) — **первый заброс делает игрок** (мод сам не закидывает), дальше: подсечка (детект по вертикальной скорости поплавка; счётчик тиков сбрасывается по id нового поплавка)/перезаброс. Ручное сматывание возвращает режим ожидания. 3 режима (BREAK_CURRENT / KEEP_ONE / ALL_RODS), переключение Shift+ЛКМ **только с удочкой в руке**. Numpad 4.
5. **Авто-ферма** (`feature/AutoFarm.java`) — при ломании зрелого урожая ставит пересадку в очередь, после исчезновения блока сажает семя из хотбара на грядку и возвращает слот. Numpad 5.
6. **Наводка ближнего боя** (`feature/MeleeAssist.java`) — пока зажата атака, доводит прицел (общий `AimAssist.smoothAim`) на цель и **держит её** (конус захвата 40°, удержания 65°); когда цель ушла/умерла — сразу перезахват **ближайшего** врага. Своих (`Friends`) не таргетит. Numpad 6.
7. **Боевой ассист** (`feature/CombatAssist.java`) — **Numpad 7 вкл/выкл, Numpad 0 циклит режимы**: CRIT (бьём только в состоянии крита) → PACKET_CRIT (форс-крит стоя, packet-hop через `ServerboundMovePlayerPacket`) → FULL. Во всех режимах: зажатая ЛКМ = авто-удар при полной шкале (`tick`); клики при недозаряженной шкале отменяются через `InputEvent.InteractionKeyMappingTriggered` (отмена `AttackEntityEvent` НЕ останавливает пакет удара — он уходит раньше).
8. **Авто-еда** (`feature/AutoEat.java`) — при сытости ≤ порога зажимает `keyUse` на самой питательной еде; берёт из хотбара, иначе SWAP-ом достаёт из инвентаря и возвращает. Чёрный список опасной/ценной еды. **Пауза в бою** (`noteCombat()`, `autoEatCombatPause` сек; при голоде ≤ 4 ест всё равно). **Гэппл-режим**: в бою при ХП ≤ `gappleHealth` (деф. 10) съедает золотое яблоко в обход паузы и чёрного списка; конец — по появлению абсорбции. Numpad 8.
9. **Авто-рефилл** (`feature/AutoRefill.java`) — отслеживает `lastItem[9]`; когда слот хотбара опустел, SWAP-ом тянет такой же предмет из инвентаря. Numpad 9.
10. **Предупреждение о прочности** (`feature/DurabilityWarning.java`) — actionbar + звук при низкой прочности брони/рук. Только конфиг (без клавиши).
11. **Бросок жемчуга** (`feature/PearlThrow.java`) — бинд **G**: берёт перл (offhand/хотбар/инвентарь) в руку, бросает, возвращает прежний предмет. Всё за один тик. Если перлов нет — actionbar «перлы кончились».
12. **HUD** (`HudOverlay.java`) — список активных фич и режимов в левом верхнем углу. Регистрируется слоем через `AddGuiOverlayLayersEvent` → `ForgeLayeredDraw.add(id, ForgeLayer)` (**в Forge 61 нет `RenderGuiEvent`/`RegisterGuiOverlaysEvent`** — только этот API). Событие может уйти до загрузки мода (Gui создаётся в конструкторе Minecraft) — страховка `ensureRegistered()` на первом тике добавляет слой рефлексией в приватный `ForgeLayeredDraw.instance` + `resolveLayers()`. Конфиг `hud`.
13. **Метка цели** (`feature/HitMark.java`) — после твоего удара игрок подсвечивается красной обводкой (glowing, видно сквозь стены) на `hitMarkSeconds` (деф. 30 c). Клиентское: `setGlowingTag(true)` каждый тик + клиентская скорборд-команда `pvph_mark` с `ChatFormatting.RED` (цвет обводки берётся из команды); прежняя команда цели запоминается и возвращается. Только конфиг (`hitMark`), без клавиши.
14. **Хот-свап элитры** (`feature/ElytraSwap.java`) — при падении (скорость < -0.5, дистанция > 2.5) элитра из инвентаря свапается на грудь (3 клика PICKUP) и раскрывается (`tryToStartFallFlying()` + `ServerboundPlayerCommandPacket.START_FALL_FLYING`); после приземления/воды нагрудник возвращается. **Не срабатывает с булавой/копьём в руке** (мейс-слэм) и **уступает воде** (если `AutoWaterBucket.isAvailable` и есть земля в 32 бл — MLG водой, элитру не надеваем). Конфиг `autoElytra`, без клавиши.
15. **ТНТ-комбо** (`feature/CartBomb.java`) — бинд **H**: рельса на блок под прицелом (3–5.5 бл) → вагонетка с ТНТ → блок-стенка перед игроком → полный натяг лука → выстрел. Требует лук с **Воспламенением** (горящая стрела взрывает вагонетку МГНОВЕННО — потому стенка ставится до выстрела). Стейт-машина в тике, watchdog 120 тиков, `AimAssist` на время комбо отключается.

16. **Авто-мост** (`feature/BridgeAssist.java`) — тумблер **B**: пока включён, ставит полный блок из хотбара под ноги и на клетку вперёд по ходу движения (по `getDeltaMovement`, стоя — по взгляду); опору ищет среди 6 соседей целевой клетки, клик по грани через `useItemOn`; кулдаун 2 тика, слот возвращается. Конфиг `bridge`.
17. **Авто-вода / MLG** (`feature/AutoWaterBucket.java`, конфиг `autoWater`, тумблер **Numpad -**): при падении (скорость < -0.5, fallDistance > 3) и земле в ~4.3 бл (луч `clip` вниз) льёт воду (ведро только из хотбара), слот/взгляд возвращает СРАЗУ (как перл). Забор наводится на сохранённую `waterPos` (работает после сдвига камеры/шага), таймаут 80 тиков. **Не срабатывает с булавой/копьём в руке** (`util/HeldItems.isMaceOrSpear`) — не сбивает заряд мейс-слэма.
18. **Координаты игроков** (в `HudOverlay`) — тумблер **Numpad .**: список видимых игроков (`mc.level.players()`) по никам с координатами и дистанцией, топ-10 ближайших. Свои (`Friends`) зелёные и первыми, чужие красные. Конфиг `playerCoords`.
19. **Свои / команда** (`feature/Friends.java`, конфиг `friends`) — список ников команды (регистронезависимо), рантайм-добавление. Влияет на цвет/порядок в HUD-координатах.
20. **Релей координат** (`feature/TeamRelay.java`, конфиг-секция `[relay]`) — раз в секунду HTTP-POST (java.net.http, фоновый поток-демон) на свой сервер: шлёт свою позицию, получает позиции команды → координаты своих видны **на любой дистанции/в любом измерении** (ванильный сервер этого не даёт). В HUD — с пометкой ⇄. Токен вшит в дефолт. Сервер — папка `relay/` (Python 3 stdlib, systemd-автозапуск на Linux-VDS, см. `relay/README.md`).

**Бренд:** отображаемое имя — «ШТРАФОСТАН TOOLS» (HUD-заголовок, префикс чата `[ШТРАФОСТАН]`, mods.toml). **modId остаётся `pvphelper`** (менять нельзя — слетят конфиг и клавиши).

Наводки (лук и ближний бой) не таргетят сквозь стену — проверка через `util/Los.java` (`level.clip`, `ClipContext`).

## Архитектура

- `PvpHelper.java` — точка входа (`@Mod`). Регистрирует конфиг; клиентскую часть поднимает только при `FMLEnvironment.dist == Dist.CLIENT`.
- `ClientBootstrap.java` — регистрирует все слушатели. Клавиши — на мод-шине через `RegisterKeyMappingsEvent.getBus(modBusGroup)`. Игровые события — через `<Event>.BUS.addListener(...)` (новый EventBus Forge 7). Тик-хендлер (`ClientTickEvent.Post`) обрабатывает переключатели и вызывает `AutoTotem.tick` / `AimAssist.tick`.
- `util/BallisticSolver.java` — численная баллистика. `simulate()` гоняет полёт снаряда тик-в-тик (гравитация + дрэг, как в MC); `solvePitch()` сканирует угол наклона для настильной траектории; `solve()` итеративно добавляет упреждение на скорость цели. Параметры снарядов в enum `ProjectileType` (ARROW / THROWN).
- `PvpConfig.java` — `ForgeConfigSpec` (тип CLIENT): секции `features` / `aim` / `pvpAssist`.
- `KeyBindings.java` — все `KeyMapping` (нумпад 1–9 — тумблеры фич, нумпад 0 — цикл режимов боя, V — наводка метательных, G — перл), категория `key.categories.pvphelper`.

Важно: фичи имеют статический флаг `enabled` (быстрый toggle клавишей) **и** проверку конфига `PvpConfig.*.get()` — оба должны быть true.

## Команды

Обёртка Gradle — `gradlew.bat` (Windows). Требуется `JAVA_HOME` на JDK 21 (Temurin установлен в `C:\Program Files\Eclipse Adoptium\jdk-21*`).

```powershell
$env:JAVA_HOME = (Get-ChildItem "$env:ProgramFiles\Eclipse Adoptium" -Directory | Where-Object { $_.Name -like "jdk-21*" } | Select-Object -First 1).FullName

.\gradlew.bat build          # собрать мод -> build/libs/pvphelper-1.0.0.jar
.\gradlew.bat runClient      # запустить тестовый клиент Minecraft с модом
.\gradlew.bat --refresh-dependencies build   # если поехали зависимости
```

Готовый JAR из `build/libs/` кладётся в `.minecraft/mods` рядом с установленным Forge 1.21.11.

## Заметки по сборке (важно — окружение с нестабильной сетью)

- API Forge 61 использует **новый EventBus 7** (`.BUS.addListener`, `getBus(modBusGroup)`), а не старые `@SubscribeEvent`/`MinecraftForge.EVENT_BUS`. При правках событий сверяйся с этим.
- Точные имена классов событий 1.21.11 могли меняться — источник истины это результат `gradlew build`.
- **Gradle wrapper переключён на локальный дистрибутив** (`gradle/wrapper/gradle-wrapper.properties` → `file:/.../scratchpad/gradle-9.3.1-bin.zip`), потому что скачивание с services.gradle.org отваливалось по таймауту. Если zip удалят — вернуть обычный `https://` URL или заново скачать.
- **ForgeGradle требует JDK 8** для генерации official-маппингов (`srg2names`) и качает его сам через Disco. При нестабильной сети архив приходит битым (`zip END header not found`). Фикс: скачать `OpenJDK8U-jdk_x64_windows_hotspot_8u492b09.zip` вручную (устойчивой докачкой `curl -C -`) в `~/.gradle/caches/minecraftforge/forgegradle/mavenizer/caches/`.
- Первая сборка декомпилирует Minecraft (несколько минут, разово, кешируется). Последующие — секунды.
